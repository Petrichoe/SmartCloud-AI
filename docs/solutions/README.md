# 排障与解决方案

这里记录项目运行过程中已经定位并验证过的故障、根因、处理步骤和复盘结论，便于后续遇到相同问题时快速检索。

## 记录规范

每篇解决方案尽量包含以下内容：

1. 现象和完整错误关键字
2. 影响范围和实际调用链
3. 根因及排查证据
4. 修复配置或代码
5. 验证方法、遗留问题和回滚方式

文档中禁止写入真实 API Key、密码、Token、私钥或带有敏感参数的完整请求；统一使用占位符。
